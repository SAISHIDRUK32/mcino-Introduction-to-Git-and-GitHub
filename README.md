# Simple Interest Calculator

## Project Overview

The **Simple Interest Calculator** is a Bash-based program that calculates simple interest using the principal amount, annual rate of interest, and time period.

This project demonstrates basic shell scripting, user input, arithmetic operations, and the use of Git and GitHub for version control.

## Formula

Simple interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal (P):** The initial amount of money.
- **Rate (R):** The annual rate of interest, expressed as a percentage.
- **Time (T):** The time period in years.

## Input

The program accepts three values from the user:

1. Principal amount
2. Annual rate of interest (percentage)
3. Time period (years)

## Output

The program displays the calculated simple interest.

## Example Calculation

Suppose the user enters:

- Principal: 1000
- Rate of interest: 5%
- Time period: 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100

**Simple Interest = 100**

## How to Run the Program

### Requirements
- Bash shell
- A terminal or command-line interface

### Steps

1. Download or clone this repository.
2. Open a terminal in the project directory.
3. Make the script executable:

   ```bash
   chmod +x simple-interest.sh
   ```

4. Run the script:

   ```bash
   ./simple-interest.sh
   ```

5. Enter the principal amount, interest rate, and time period when prompted.
